About Me

자기소개

저는 구조를 먼저 그리는 엔지니어입니다.

근거로 설계하고, 먼저 움직입니다.

반갑습니다. 저는 코드를 작성하기 전에 "왜 이 구조여야 하는가"를 먼저 고민하는 백엔드 개발자입니다.

화려한 기능보다 변화에도 흔들리지 않는 견고한 설계에 관심이 많고, 기술을 선택할 때는 감이 아닌 근거를 직접 찾아 팀을 설득하는 과정을 좋아합니다. 특히 상황에 맞는 아키텍처를 고민하고 설계하는 과정에서 가장 큰 몰입을 느끼며, 모니터링 환경 구축이나 동시성 제어처럼 서비스의 안정성을 직접 책임지는 영역에 관심이 많습니다.

최근에는 Claude Code와 Codex를 오케스트레이션하여 개발과 코드 리뷰를 자동화하는 워크플로우를 실험하고 있으며, AI 도구를 활용하되 설계 판단은 스스로 내리는 개발자를 지향하고 있습니다. 어렵거나 부담스러운 작업일수록 먼저 나서는 편이고, 제가 먼저 움직였을 때 팀원들도 함께 따라와 주는 순간에 가장 큰 보람을 느낍니다.
